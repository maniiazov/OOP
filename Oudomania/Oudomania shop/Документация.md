# Документация сайта Oudomania

## О чём этот проект

Oudomania — небольшой сайт-магазин парфюмерии. В нём есть главная страница, страницы каталога и новинок, категории товаров и корзина.

## JavaScript

Основной JavaScript находится в файле `js/shop.js`. Он отвечает за работу корзины:

- добавляет товар по кнопке «В корзину»;
- показывает количество товаров рядом со значком корзины;
- сохраняет корзину в `localStorage`, поэтому она остаётся после перехода на другую страницу или перезагрузки;
- выводит товары и общую сумму на странице корзины;
- позволяет увеличить или уменьшить количество товара и удалить его.

В корзину добавляются карточки, у которых есть кнопка с атрибутом `data-cart-add`. Скрипт подключён внизу HTML-страниц, например так:

```html
<script src="../js/shop.js"></script>
```

На странице корзины используются атрибуты `data-cart-items`, `data-cart-total` и `data-checkout`. По ним скрипт находит место для списка товаров, суммы и формы оформления.

## Как попробовать

1. Откройте страницу новинок или одну из страниц категорий.
2. Нажмите «В корзину» у понравившегося аромата.
3. Перейдите в корзину по значку 🛒.
4. Измените количество кнопками «+» и «−» или удалите товар.

Данные хранятся в браузере отдельно для каждого сайта. Если очистить данные сайта в браузере, корзина тоже очистится.

## Структура папок

- `templates/` — главная страница сайта.
- `pages/` — каталог, категории, корзина и другие страницы.
- `style/` — таблицы стилей.
- `js/shop.js` — логика корзины.
- `img/` — изображения товаров и оформления.

## Что ещё нужно для настоящего магазина

Сейчас корзина работает в браузере. Для реального оформления заказа понадобится сервер, который примет заказ и безопасно обработает оплату. Не вводите данные банковской карты в демонстрационную форму сайта.
